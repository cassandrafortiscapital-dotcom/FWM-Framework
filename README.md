# Fortis Site Prototype (Option A)

A simple clickable prototype of the site framework: plain HTML, white background,
black text, labeled placeholders, every link wired up. This is for walking through
the structure and flow -- not final copy, content, or design.

Open index.html in any browser to click through it locally.

--------------------------------------------------------------------
PUT IT ONLINE WITH VERCEL (free, no coding tools needed)
--------------------------------------------------------------------

You will do this in the browser. First UNZIP this file -- GitHub needs the
individual files, not the .zip.

1. GitHub account: sign up (free) at https://github.com if you don't have one.

2. New repository: click the "+" (top right) -> "New repository".
   Name it e.g. "fortis-prototype". Leave it Public or Private. Click
   "Create repository".

3. Upload the files: on the new repo page click "uploading an existing file"
   (or "Add file" -> "Upload files"). Drag in ALL the unzipped files
   (index.html, styles.css, and every other .html file). Then click
   "Commit changes".

4. Vercel account: go to https://vercel.com, click "Sign Up", and choose
   "Continue with GitHub" so the two are connected.

5. Deploy: in Vercel click "Add New..." -> "Project", find your
   "fortis-prototype" repository, click "Import", then "Deploy".
   In under a minute you'll get a live URL like
   https://fortis-prototype.vercel.app that you can open on any device.

6. Updates later: when you want changes, I'll send updated files; you repeat
   step 3 (upload/replace) and Vercel redeploys automatically.

Home page is index.html, so Vercel serves it as the site's front page.
