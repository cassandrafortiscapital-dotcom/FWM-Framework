# Fortis Site Prototype (Option A)

A simple clickable prototype of the site framework: cream (#F4F1EA) background,
Montserrat text, labeled placeholders, every link wired up. For walking through
the structure and flow -- not final copy, content, or design.

Open index.html in any browser to click through it locally.

--------------------------------------------------------------------
PUT IT ONLINE WITH VERCEL (free, no coding tools needed)
--------------------------------------------------------------------
First UNZIP this file -- GitHub needs the individual files, not the .zip.

1. GitHub account: sign up free at https://github.com if needed.
2. New repository: "+" (top right) -> "New repository". Name it e.g.
   "fortis-prototype". Click "Create repository".
3. Upload files: "Add file" -> "Upload files". Drag in ALL the unzipped files
   (index.html, styles.css, insights-bg.jpg, and every .html file). Commit.
4. Vercel account: https://vercel.com -> "Sign Up" -> "Continue with GitHub".
5. Deploy: "Add New..." -> "Project" -> import your repo -> "Deploy".
   You'll get a live URL like https://fortis-prototype.vercel.app in ~1 min.
6. Updates: upload/replace the changed files in GitHub; Vercel redeploys.

Home page is index.html, served as the site's front page.
